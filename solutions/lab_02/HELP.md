# Как разобраться в лабораторной 2

Начни с `task_1.py`. Задания 1–4 выполняются сверху вниз: прочитай прогноз, затем по одной строке проследи изменения. `print()` показывает результат, `assert` проверяет условие: если оно неверно, программа остановится с ошибкой.

## 1 Два имени и один список

```python
first = [10, 20]
second = first
second.append(30)
```

Здесь список один, а имён два. Поэтому `first` тоже покажет `[10, 20, 30]`. Присваивание не копирует список.

Если выполнить `second = [10, 20]`, создастся другой список. Теперь изменения `second` не затрагивают `first`.

`==` означает «значения равны», `is` — «это один объект». `id()` — идентификатор объекта во время его жизни.

## 2 Три способа получить второй список

- `alias = original`: тот же список.
- `shallow = original.copy()`: внешний список новый, вложенные строки общие.
- `deep = copy.deepcopy(original)`: вложенные списки тоже копируются.

В `task_2.py` функция `show_lists()` только печатает четыре списка и их идентификаторы. `def` определяет функцию; строка `show_lists()` запускает её. Списки созданы перед первым вызовом функции.

В матрице `[[0] * 3] * 3` повторяется одна и та же строка. Вариант `[[0] * 3 for _ in range(3)]` создаёт строку отдельно три раза. `_` — имя переменной цикла, значение которой здесь не используется.

## 3 Когда объект исчезает

Сильная ссылка удерживает объект в памяти. Новое имя или элемент контейнера могут добавить такую ссылку. `del` удаляет имя, `clear()` очищает контейнер.

Слабая ссылка объект не удерживает. Поэтому после удаления последней сильной ссылки запись исчезает из `WeakValueDictionary`. `class Record: pass` создаёт простой тип объекта без дополнительных свойств — он нужен для опыта со слабыми ссылками.

## 4 Почему нужен сборщик мусора

Представь два списка, которые ссылаются друг на друга. Внешние имена удалены, но внутри цикла ссылки остались. Подсчёт ссылок сам по себе такой цикл не уберёт. Сборщик ищет объекты, до которых программа больше не может добраться.

`gc.disable()` выключает автоматическую сборку, `gc.collect()` запускает ручную, `gc.enable()` включает автоматическую обратно. Часть `finally` выполняется даже при ошибке внутри `try`, поэтому сборщик не останется выключенным.

## 5 Как устроено измерение памяти

`task_5.py` запускает `main()` из `memory_report.py`. Измерения вынесены в один файл, чтобы не копировать их дважды.

1. `measure(name)` выбирает объект обычными `if/elif`, измеряет его и возвращает словарь с результатами.
2. `collect_measurements()` собирает эти словари в список `results`, отдельно сохраняет шаги роста списка в `growth` и считает отношение пиков.
3. `print_report()` печатает уже сохранённые результаты.
4. `main()` вызывает эти функции по порядку и выполняет проверки.

`result['peak']` означает «возьми значение по ключу peak из словаря». В `results[6]` лежит результат для большого списка, в `results[7]` — для `range`: нумерация начинается с нуля.

`sys.getsizeof()` показывает размер самого объекта. `tracemalloc` отслеживает выделение памяти после `start()`. `current` — сколько отслеженной памяти занято сейчас, `peak` — максимум за время измерения. Деление на 1024 переводит байты в КиБ, `round(..., 4)` округляет до четырёх знаков после запятой.

В конце файла условие `if __name__ == '__main__':` запускает программу, когда файл открыт напрямую. При `import` оно не выполняется: иначе измерения запускались бы сразу при подключении файла.

Для защиты главное уметь объяснить: почему присваивание не копирует данные, что остаётся общим при поверхностной копии, чем слабая ссылка отличается от сильной, зачем нужен сборщик циклов и почему `range` экономнее большого списка.
